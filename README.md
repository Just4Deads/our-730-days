# Наша історія — 730 днів ❤️

Персоналізований романтичний сайт Івана для Марини. Дата початку стосунків: **06.11.2024**.

## Файли
- `index.html` — сторінки та розділи сайту.
- `styles.css` — оформлення, анімації та мобільна адаптація.
- `script.js` — лічильник, 100 причин, листи, вікторина, мрії та секретні завдання.
- `assets/` — ваші фотографії, музика й відео.

## Ваші медіафайли вже додані
У папці `assets/` є 28 фотографій (`photo-1` … `photo-28`), пісня `our-song.mp3` та відео `our-video.mp4`. Усі 28 фотографій підключені до галереї та приведені до звичайного JPEG, сумісного з браузерами. Галерея завантажує знімки поступово, коли вони наближаються до екрана.

Щоб замінити матеріали, залиш ті самі назви файлів у папці `assets/`. Для нових фотографій використовуй послідовні назви `photo-1` … `photo-28` і відповідні розширення, а в `index.html` за потреби онови шлях.

## Як редагувати 100 причин, листи та вікторину
Відкрий `script.js` у редакторі коду. На початку файлу є об’єкт `CONFIG`:
- `displayNames` — імена Івана та Марини;
- `reasons` — усі 100 причин, кожна окремим рядком;
- `letters` — чотири листи;
- `quiz` — запитання та правильні відповіді.

Зараз секретний код — `06112024` (дата початку стосунків без крапок). Після введення потрібно знайти три зірочки: у першому екрані, в історії та біля списку мрій. Прогрес зберігається в браузері на цьому пристрої.

## Перевірка на комп’ютері
Відкрий `index.html` у браузері. Для локальної перевірки цього достатньо.

## Публікація через GitHub Pages
1. Створи новий публічний або приватний репозиторій на GitHub.
2. Завантаж **вміст** папки `our-730-days` у корінь репозиторію (файли `index.html`, `styles.css`, `script.js` і папку `assets`). Не завантажуй ZIP замість файлів.
3. Відкрий `Settings` → `Pages`.
4. У `Build and deployment` вибери `Deploy from a branch`.
5. Branch: `main`, Folder: `/ (root)`, натисни `Save`.
6. Після публікації GitHub покаже адресу сайту в цьому ж розділі.

**Важливо:** не додавай у репозиторій нічого приватного, чого не хочеш показувати за посиланням. Усі файли статичного сайту та медіа в репозиторії можуть бути доступні тим, хто має доступ до нього.
